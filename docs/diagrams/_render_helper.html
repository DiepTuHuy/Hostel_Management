Render 7 PNG sơ đồ Use Case (phiên bản đơn giản)

7 sơ đồ UC (Hình 2.1–2.6 + 2.6b) đã được đơn giản hoá: bỏ màu fill ở package, dùng cùng một skinparam (background #F5F7FB, border #3A5BC7), associations dùng --.

Cách dùng:
1. Bấm nút "▶ Tải xuống" bên dưới — trình duyệt sẽ tự fetch 7 PNG từ plantuml.com và tải về thư mục Downloads.
2. Copy 7 file PNG (image1.png ... image6.png, image55.png) từ Downloads vào docs/diagrams/png/.
3. Trong file .docx: chuột phải lên ảnh UC cũ → Change Picture → From File → chọn PNG mới.
